GETTING STARTED

Your way in.

The simplified extension installation guide.

On desktop.

  1. Download the build and unzip it.
  2. Open chrome://extensions in Chrome or your Chromium browser.
  3. Enable Developer mode.
  4. Select Load unpacked and choose the folder containing manifest.json.
  5. Pin the extension and click its icon to open it.

On phone.

Mobile installation depends on the browser and platform. Your mobile browser must support unpacked Chromium extensions.

  1. Download and extract the build.
  2. Open your browser’s extension manager.
  3. If supported, enable Developer mode and load the extracted extension.
  4. Open Illyasaka’s X profile and launch the extension.

Standard Chrome on Android and Safari on iPhone cannot load this desktop Chromium build. If your browser has no compatible loader, use the desktop guide.
