Phone setup. Simplified.

Install the simplified extension on your phone.

Simplified Android setup: download Kiwi Browser, install the APK, enable developer mode, import the extension ZIP, then open Illyasaka’s profile.

Before you start

Download both files on your phone first: Kiwi Browser APK and the extension ZIP.

Download Kiwi Browser APK Download Extension ZIP Open Illyasaka's Autodrain
Install APK files only when you trust the source. Android may ask you to allow installs from your browser or file manager.
1

Download Kiwi Browser APK

Tap the button below to open the Kiwi Browser APK download directly from GitHub.

Download Kiwi Browser APK
2

Install the APK

Open the downloaded APK and install Kiwi Browser. If Android blocks it, allow installation from your browser or file manager.

3

Open the Kiwi menu

Tap the three dots in the top-right corner.

4

Enable developer mode

Go to Extensions

5

Load the extension ZIP

Click on + (from .zip), then load Illyasaka's extension ZIP.

6

Activate and run it

Once the extension is enabled, open Illyasaka’s throne and let the extension run.
